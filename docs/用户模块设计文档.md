# 用户模块设计文档

> 版本：v1.0 | 日期：2026-07-13 | 作者：nijika

## 1. 模块概述

用户模块提供注册、登录、注销、用户信息管理等功能，基于 Session 实现登录态维护，通过 AOP 注解 `@AuthCheck` 实现接口级权限控制。

## 2. 数据模型

### 2.1 用户表（user）

| 字段         | 类型          | 约束                          | 说明               |
| ------------ | ------------- | ----------------------------- | ------------------ |
| id           | bigint        | PK, 雪花 ID                  | 用户 ID            |
| userAccount  | varchar(256)  | NOT NULL, UNIQUE              | 账号               |
| userPassword | varchar(512)  | NOT NULL                      | 密码（MD5 加盐）   |
| userName     | varchar(256)  |                               | 昵称               |
| userAvatar   | varchar(1024) |                               | 头像 URL           |
| userProfile  | varchar(512)  |                               | 简介               |
| userRole     | varchar(256)  | NOT NULL, DEFAULT 'user'      | 角色：user / admin |
| editTime     | datetime      | NOT NULL, DEFAULT NOW         | 编辑时间           |
| createTime   | datetime      | NOT NULL, DEFAULT NOW         | 创建时间           |
| updateTime   | datetime      | NOT NULL, DEFAULT NOW, 自动更新 | 更新时间         |
| isDelete     | tinyint       | NOT NULL, DEFAULT 0           | 逻辑删除           |

索引：`uk_userAccount`（唯一）、`idx_userName`（普通）。

### 2.2 角色枚举（UserRoleEnum）

| 枚举值 | value   | 说明   |
| ------ | ------- | ------ |
| USER   | user    | 普通用户 |
| ADMIN  | admin   | 管理员   |

## 3. 数据传输对象

### 3.1 请求 DTO

| 类名              | 用途         | 核心字段                                            |
| ----------------- | ------------ | --------------------------------------------------- |
| UserRegisterRequest | 注册       | userAccount, userPassword, checkPassword             |
| UserLoginRequest    | 登录       | userAccount, userPassword                            |
| UserAddRequest      | 创建用户（管理员） | userName, userAccount, userAvatar, userProfile, userRole |
| UserUpdateRequest   | 修改用户（管理员） | id, userName, userAvatar, userProfile, userRole      |
| UserEditRequest     | 编辑个人信息（本人） | userName, userAvatar, userProfile                |
| UserQueryRequest    | 分页查询（管理员） | id, userName, userAccount, userProfile, userRole + 分页排序 |
| DeleteRequest       | 删除（通用） | id                                                  |

### 3.2 响应 VO

| 类名        | 用途               | 相比 User 实体隐藏的字段                     |
| ----------- | ------------------ | -------------------------------------------- |
| LoginUserVO | 登录后返回当前用户 | userPassword, editTime, isDelete             |
| UserVO      | 对外展示用户信息   | userPassword, editTime, updateTime, isDelete |

## 4. 接口清单

### 4.1 公开接口（无需登录）

| 方法 | 路径              | 说明     | 请求体              | 响应体                  |
| ---- | ----------------- | -------- | ------------------- | ----------------------- |
| POST | /user/register    | 用户注册 | UserRegisterRequest | `Long`（新用户 ID）     |
| POST | /user/login       | 用户登录 | UserLoginRequest    | `LoginUserVO`           |

### 4.2 登录用户接口

| 方法 | 路径              | 说明             | 请求体            | 响应体          |
| ---- | ----------------- | ---------------- | ----------------- | --------------- |
| GET  | /user/get/login   | 获取当前登录用户 | 无                | `LoginUserVO`   |
| POST | /user/logout      | 用户注销         | 无                | `Boolean`       |
| GET  | /user/get/vo      | 根据 id 获取用户 VO | 参数 id        | `UserVO`        |
| POST | /user/edit        | 编辑个人信息     | UserEditRequest   | `Boolean`       |

### 4.3 管理员接口（@AuthCheck）

| 方法 | 路径                 | 说明               | 请求体            | 响应体          |
| ---- | -------------------- | ------------------ | ----------------- | --------------- |
| POST | /user/add            | 创建用户           | UserAddRequest    | `Long`          |
| GET  | /user/get            | 根据 id 获取完整用户 | 参数 id         | `User`          |
| POST | /user/delete         | 删除用户           | DeleteRequest     | `Boolean`       |
| POST | /user/update         | 修改用户           | UserUpdateRequest | `Boolean`       |
| POST | /user/list/page/vo   | 分页查询用户       | UserQueryRequest  | `Page<UserVO>`  |

## 5. 权限与安全

### 5.1 权限模型

```
公开接口 ── 无需登录（register、login）
    │
登录接口 ── 需 Session 有效（get/login、logout、get/vo、edit）
    │
管理员接口 ── @AuthCheck(mustRole = "admin")（add、get、delete、update、list/page/vo）
```

权限校验通过 AOP 切面 `AuthInterceptor` 实现，拦截所有标注 `@AuthCheck` 的方法，从 Session 获取当前用户角色与要求角色比对。

### 5.2 安全措施

| 安全点         | 实现方式                                                         |
| -------------- | ---------------------------------------------------------------- |
| 密码存储       | MD5 加盐（盐值固定），不明文存储                                 |
| 数据脱敏       | 对外返回 `LoginUserVO` / `UserVO`，隐藏密码等敏感字段            |
| 防越权提权     | `/edit` 接口 DTO 不含 `userRole` 字段，`BeanUtil.copyProperties` 不会拷贝 |
| 防水平越权     | `/edit` 接口用户 ID 从 Session 获取，不由前端传入                 |
| Long 精度丢失  | `JsonConfig` 将 Long 序列化为 String，防止前端 JS 精度丢失       |
| 逻辑删除       | MyBatis-Flex `@Column(isLogicDelete = true)`，数据不物理删除     |
| 默认密码       | 管理员创建用户时默认密码 `12345678`                              |

## 6. 核心业务逻辑

### 6.1 注册流程

1. 校验参数非空、账号 ≥ 4 位、密码 ≥ 8 位、两次密码一致
2. 查询账号是否已存在（唯一约束）
3. MD5 加盐加密密码
4. 生成默认昵称（"用户" + 账号前 3 位 + 随机数），角色设为 `user`
5. 插入数据库，返回用户 ID

### 6.2 登录流程

1. 校验参数非空、账号 ≥ 4 位、密码 ≥ 8 位
2. 加密密码后查询 `userAccount + userPassword` 匹配的用户
3. 将用户对象存入 Session（`USER_LOGIN_STATE`）
4. 返回脱敏后的 `LoginUserVO`

### 6.3 编辑个人信息（/edit）

1. 从 Session 获取当前登录用户 ID
2. 将 `UserEditRequest`（仅含昵称、头像、简介）拷贝到 User 实体
3. 设置 ID 为当前用户 ID，执行更新
